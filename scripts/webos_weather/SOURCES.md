The two MIT-licensed app forks use same-origin GET routes at `/services/weather/{weather,places,places/reverse,history}`. Weather returns metric values and UTC timestamps with provider, forecast issue time, observation or forecast origin, expiry and alert status. Unreported values are null. Daily ranges summarize the provider's published time samples. The server identifies itself to providers as WebOS-Weather with the public project URL. Location coordinates are rounded to hundredths of a degree before upstream requests and in-memory caching.

Point forecasts and recent station observations in NWS coverage use [NWS](https://www.weather.gov/documentation/services-web-api). Elsewhere the point forecast is [MET Norway Locationforecast](https://api.met.no/weatherapi/locationforecast/2.0/documentation), licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Weather alerts require a fresh NWS active-alert response and an unexpired warning. Maps' large model fields and tiles go directly to their respective sources.

Place lookup uses locally indexed GeoNames cities, with attribution in GeoNames-LICENSE.txt. Historical temperatures and precipitation are actual [NCEI Daily Summaries](https://www.ncei.noaa.gov/access/services/data/v1) for a nearby reference station. The station index contains GSN, WMO and US WBAN entries from [GHCN-Daily station metadata](https://www.ncei.noaa.gov/pub/data/ghcn/daily/ghcnd-stations.txt). Missing years or lack of station coverage are left empty.
