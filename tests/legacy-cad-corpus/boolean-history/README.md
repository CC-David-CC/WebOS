# Signed public Boolean-history plate workflow

Status: prepared, **not run or qualified**. Await the parent's frozen matched
full app/bundle/signed fixture pins. Tests only; no product files are changed.

The actual-command driver creates a fully constrained100×50 rectangle on XY0,
extrudes20mm through the new registered dd666/8d5 build, then creates five
independent empty XYplanes at z=-1 and appends one ordinary Circle per source.
The tools have fixed22mm depths: one R5 center bore and four R2 bores at8mm
corner offsets. Each genuine selected-profile tool is subtracted through the
registered public Boolean command. The original discovered connector keys must
survive all five cuts, then select two oppositeR3 fillets and the other two
size1 chamfers. Native measurements, validity, census, bounds and six actual
source contexts are checked independently at every cut/edge stage.

Public refusal controls preserve the whole accepted native source/history,
geometry and journal. Undo/Redo restores the full chain. Normal native Save,
server sync and a fresh signed public Open must preserve the exact source and
symbolic operand/edge intents; a reopened fillet3→4 edit, Undo/Redo, resave and
second fresh Open must work. Both own saved files get independent offline data
oracles. Native point/cylinder geometry checks remain separately qualified
component evidence: this driver does not invent a public observation endpoint.

All authoring uses existing registered desktop commands and returned IDs/current
revisions. The reused qualified `../edge-treatments/harness.mjs` supplies login,
runtime pins, normal Save/sync/Open and detached accepted-state read assertions.
Its private `__CAD_APP` access is read-only apart from the existing normal
snapshot serialization; it never writes source/model/history or fabricates a
successful Worker reply. Test account state is new in the parent's private
fixture. Old tests/evidence remain unchanged.

The fixed tool depth is deliberate. This is **not semantic through-all** or
source/depth dependency qualification. No public hole feature, arbitrary Boolean
naming, general kernel robustness, UI, Files re-audit or fullGate1 completion is
claimed. Source/depth edits and true hole intent remain separate gate work.
