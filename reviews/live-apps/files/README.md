# Files

In a disposable account on ksu.codes, uploaded a different text file at each viewport, selected it, downloaded it, and compared its bytes to the original. All four downloads matched. Three fresh sign-ins also saw the file uploaded from the phone. Closing Files worked at every size.

At 820 × 1180 the selected filename shifted down by 38 CSS pixels when the toolbar wrapped. The measured shift was zero at 390 × 844, 1920 × 1080 and 3840 × 2160. The tablet behavior is in the fix queue. Phone and tablet used Chromium touch emulation. Physical touch devices and Safari still need testing.
