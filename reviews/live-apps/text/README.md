# Text Editor

Created a note on the phone and used Save As to place it in Documents. In a fresh signed-in browser at each subsequent size, opened the note through Files, compared its complete contents, appended text and waited for “Saved to your account.” A fifth browser at 1920 × 1080 reopened the file and verified every edit, including the 4K edit. Tablet Files navigation used double taps. The mobile software keyboard and IME still need hardware testing.

Passed in signed-in Chromium on ksu.codes at 390 × 844, 820 × 1180, 1920 × 1080 and 3840 × 2160 CSS pixels. The phone and tablet contexts emulated touch. Physical iPad, phone and Safari behavior remain unverified.
