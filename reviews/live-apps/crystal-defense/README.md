# Crystal Defense

Choose a socket, place a tower, launch the first wave and pause.

Toolbar and socket labels blend into their light button backgrounds on compact screens. The maximized 1080p canvas measures 1,357 pixels high, so part of the scene falls below the viewport.

Tested in Chromium using a disposable account on ksu.codes release `8d93a81d687eb85f012d0dde801c2a27a69e3d7adc49bae91a4c69c790f91be3`. Physical-device input and performance remain to be checked.
