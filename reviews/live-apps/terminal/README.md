# Terminal

Opened Programming → Terminal from four fresh Chromium sessions on ksu.codes. Each session wrote a text file into the Linux home directory and read it back. The signed account Files API returned the same contents. On the tablet, 1080p and 4K layouts, the shell also read the file created on the phone. The window closed successfully at all four sizes.

At 390 × 844 the command wrapped across lines, with the prompt visible and the shortcut buttons in two rows. At 820 × 1180 the tablet also used two button rows. Both desktop sizes kept the shortcuts in one row. Phone and tablet used touch emulation with keyboard events. Opening and dismissing physical devices' on-screen keyboards still needs testing.
