# Audio Editor (AudioMass)

Audio Tools → Audio Editor opens a 2.016-second Bruno sample, paused and ready to play. File → Open from My files replaces the sample with the selected recording. Opening a recording directly from Files skips the sample.

On a 390 × 844 touch viewport, a tester applied Effects → Invert to the sample, used Save WAV as, then played and stopped the edited audio. In fresh sessions at 820 × 1180, 1920 × 1080 and 3840 × 2160, the same account reopened and played the phone's WAV. The phone clips the right edge of the MultiTrack control. Physical-device touch and microphone quality remain open.

An existing version-2 browser mirror retained its local file across the release. Both an MP3 and a WAV opened from Files and advanced the playhead. A separate desktop listening check confirmed playback of a saved Narrator MP3 after a normal refresh.
