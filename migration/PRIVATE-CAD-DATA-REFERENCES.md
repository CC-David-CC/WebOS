# Private CAD case data references

This catalogue assigns639 frozen data records across40 historical CAD cases to
parent whole-system test reference ownership. Thirty-eight cases have already
owned test drivers (626 records). Two additional cases use owned historical notes
and verified recorded-input/inventory context (13 records). Those notes are not
fabricated test drivers. This assigns preservation/reference ownership, not every
file's producer, input/output use, future reuse or current compatibility.
See [additional case context](DEFERRED-CAD-CONTEXT.md) for the nine historical
source pins (eight current matches and one preserved different version) and a
runtime inventory whose payload presence remains unqualified.

Raw material stays in the existing owner-only, self-contained recovery Git
capture, outside the assembled source repositories and web roots. No raw model, receipt, image,
log, key, account state or user document was copied into this parent or a release.
The private catalogue identifies source path, capture commit, Git blob, SHA256,
mode, case source anchor, bounded data role and retained path history. Another
agent can restore selected records privately from that recovery without the old
workspace. The recovery remains on this laptop, not a proven off-machine backup.

Restored bytes existed only in that ephemeral namespace. No old module, test,
model transition or geometry engine executed. Captured receipts/PASS text are
not current acceptance; same-origin trust and real authorization still apply.

These records are not registered as current test/build inputs. Before reuse,
identify the actual per-file producer/consumer and intended file identity,
restore only approved inputs privately, review account/credential/privacy
content, port locators/public APIs and qualify geometry/fixture behavior against
the selected runtime. Never load raw recovery through a web route, reuse real
account state, infer source lineage from equal bytes, manufacture success or
weaken assertions. ACAD and original JSketcher retain separate component ownership.
