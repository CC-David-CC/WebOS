# Student guide: simplified webOS preview

This is a prototype for coursework and engineering experiments. Sign in to use the desktop. Open apps from Applications; your previous windows may be restored. Apps run in your browser, while the server provides account and file services.

## Keep your work in My files

Open **System Tools → Files** and choose **My files**. Use **New / Upload** to create a file or folder or upload files from your computer. Select a supported file to open its associated app, or use **Browse My files** inside a supported app. In an editor, save explicitly and watch its status. A save first updates this browser's copy; the server sync happens afterward. Files shows when it has checked the server and when local changes are waiting to sync. If the browser is offline or a conflict is reported, do not assume the server has the latest copy. Reconnect and resolve the issue in Files before relying on another device.

A browser can clear its local storage. The server copy helps recovery only after synchronization succeeds. There is no restore/history feature yet. Deletions synchronize, so deleting a file can remove both copies. Keep independent backups of important coursework where possible. The desktop does not currently offer a general download-to-computer action, so plan for that limitation before relying on it as your only copy.

Linux has a separate temporary filesystem that resets on reboot. Files can browse it using the **temp_linux** drive; other desktop apps use My files. To open a Linux file in another app, select it in temp_linux and use **Copy to account**. The two drives do not automatically synchronize. My files allows files up to 128 MiB; individual apps can have smaller limits.

## Common tasks

On a phone, open Files and tap **New / Upload** to create a folder, create a file, or bring a file in from your device. To open an item, tap it and then tap **Open**. On a desktop, use the same button or right-click empty space. Select one file to use **Rename**, **Move to…**, or **Copy to…**; moves require the file and destination folder to finish syncing first. Folder moves and copies are not available. New windows fill the phone screen; on a desktop they open at half width, alternating left and right. Use the window’s maximize control to fill the screen or return to its previous size.

- **Notes or code:** Create or upload a `.txt`, `.md`, `.py`, or other supported text file in Files, open it in Text Editor, edit and save. A new Text document asks where to save in My files; use **Choose folder** to browse folders, then enter the filename. Text has line numbers, search and replace, undo, and syntax highlighting for Python and JavaScript/TypeScript. Reopen it from Files to check the saved copy.
- **Reports:** Open Document Editor, write and save its `.doc` or `.codidoc` project in My files. Those files use this application's own format, not a Microsoft Word document. Export a PDF into My files, or preview it using the separate PDF Viewer.
- **Reading PDFs:** Open PDF Viewer and choose **Open from My files**. Use Previous, Next and zoom to read. Select Reload to check the server and open the current saved copy. If the check fails, the current page stays open. You can upload a PDF into My files using Files. You can search and select embedded text. Scanned pages need OCR, and annotations and PDF editing are not available.
- **Spreadsheets:** Open Spreadsheet and save a `.codisheet` workbook in My files. You can import CSV or XLSX as a copy and export the current sheet as CSV values or the workbook as XLSX. CSV does not keep formulas or formatting, and advanced Excel features may not be preserved; check results before relying on them.
- **Data:** Upload a CSV to My files, then open it in Data Explorer. Run a SQL query and choose **Save results CSV** to save its results to My files. DuckDB and Perspective run in the browser. Save analysis separately as a `.codi-data.json` project to keep the SQL and viewer settings; keep its source CSV in My files. Viewer filters and charts are not included in the exported CSV, and large datasets may exceed the device's memory.
- **Images:** Open a PNG, JPEG or WebP from My files in Image Editor. Save updates that image; use Save As to make a separate copy. Animated GIF editing isn't available yet.
- **Python Notebook:** Applications → Programming → Python Notebook — Browser starts JupyterLite with Pyodide. Open a notebook from My files or choose a folder and select **Save to Files**. After its first save, edits synchronize automatically while the window is open. The browser kernel is not a full Linux process environment; only run notebooks you trust. The separate Linux notebook launcher is not yet available; Terminal runs in the temporary Linux guest.
- **Microcontrollers:** Arduino Simulator runs compiled ATmega328P `.hex` firmware in the browser. Try the Blink or Serial Echo example; save the visible serial output to My files as text if you need it later. It does not compile sketches or validate physical hardware.
- **Pico:** Pico Simulator has a built-in Blink example. MicroPython requires your own compatible ROM and UF2 files in My files; save a `.pico` project explicitly to retain simulated flash. Hardware emulation is incomplete and does not validate a physical board.
- **Digital logic:** Load a gate, half-adder, full-adder or multiplexer example in Digital Logic. Toggle the diagram inputs, or calculate a truth table and save it as CSV. Save the `.logic.json` circuit separately; timing, electrical behavior and sequential logic are not modeled.
- **Circuit simulation:** Circuit Simulator starts with a voltage divider and offers an RC filter and rectifier. Change the circuit, then save a `.circuit` file to My files. It is an interactive model, not a guarantee of a real circuit’s behavior.
- **Electronics:** In Electronics Design, use the breadboard, schematic and PCB tabs to work on one design. On a sufficiently large window, **Show three views** places them side by side; click a view to edit it. Save the `.dez` project to My files. Review simulations and manufacturing output independently before using physical hardware.
- **3D printing:** Kiri:Moto, Mesh:Tool and G-code Preview run in the browser. Open a supported model or G-code file from My files; explicitly export results to My files. In Kiri:Moto, Save workspace stores a snapshot of your models and slicing settings in My files; save again after changes. Open workspace restores a snapshot and replaces the current workspace after confirmation. In Mesh:Tool, Save workspace similarly stores an editable `.meshproj` snapshot; save again after changes and export an STL separately when needed. G-code Preview starts at zero with no stored machine offsets; its visualization is not a machine compatibility or safety check. Review the machine and print settings yourself before sending anything to a printer.
- **Replicad:** Enter box or cylinder dimensions and an optional centered through-hole; build the preview and inspect its calculated volume. Save the editable `.replicad.json` project, then create a separate STL or STEP export. This is a primitive generator, not a full CAD editor or manufacturing check.
- **Diagrams:** diagrams.net saves `.drawio`, Excalidraw saves `.excalidraw`, and SVG-edit saves `.svg` to My files. Complex files and physical-phone touch have not been broadly verified.
- **Embroidery:** Embroidery Studio saves editable `.stitchfoundry` projects and exports stitches. Stitch Converter turns supported SVG artwork into a preview and machine files; save editable `.stitch.svg` artwork separately. Both are experimental: check thread order, hoop size and a test sew before production.
- **Audio:** Audio Editor opens a track from My files and saves a separate WAV there. Choose 16-bit, 24-bit or float output as needed. Multitrack sessions do not yet save through My files; compressed audio can require much more device memory after decoding.
- **Calculator:** Enter an expression or use the keypad. Select degrees or radians; inverse trigonometry follows the same setting. EE enters a power of ten, such as `6.02e23`. Results are temporary and use floating-point arithmetic.
- **Browser:** This experimental browser has a temporary profile. It can open a single HTML file from My files and save supported downloads there, but sibling local files, persistent profiles and audio are not yet supported. The relay restricts destinations; broad website compatibility and safety for sensitive browsing are not established.
- **Falling Blocks:** The preview game runs in its own window. Save a game to My files to resume it later. Its rules are project-specific and do not claim official Tetris compatibility.
- **Desktop Help:** Open Help for the beta notice, contact email and the temporary Linux filesystem reminder.

Some embedded tools still offer an upload from your computer or use their own file controls. Their presence does not guarantee that every feature is integrated with My files. Shared System Tools are capabilities for applications; a disabled menu entry does not mean it has its own interactive window.

## Security and current limits

The notebook currently requires an extra JavaScript capability under its notebook URL and runs on the same origin as the desktop. Treat notebooks and third-party content as trusted; isolation for untrusted notebooks is unfinished. Linux SSH, per-user relay logs, and a native Linux notebook kernel are not yet enabled in this preview. Check the app's status and keep copies of important work while the prototype is being developed.
