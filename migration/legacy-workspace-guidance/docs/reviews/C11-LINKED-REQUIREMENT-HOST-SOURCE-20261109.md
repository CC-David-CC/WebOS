## Lifecycle invariants

| Transition | Preserved boundary |
| --- | --- |
| Current source→discovery | Exact inspected target/source datum and issued revisions; refs come from real Native/index context. SourceRole/labels are descriptive, not selector authority. |
| Prepared definition→publish | Existing PM operation and one journal; source/geometry/material unchanged, no new feature allocator/state. |
| Accepted definition→read | Protected real accepted-definition custody, scoped owner/currentness; no hypothetical caller definition passed as accepted truth. |
| Read→stale/cancel/cleanup failure | Existing real outer error retained through scoped settlement, never converted into successful unresolved facts by Host. |
| Known geometry loss→unresolved | Backend's finite actual reason/null-fact contract only; authored requirements remain. No retarget or Host healing. |
| Explicit repair/travel/Open | Same shared metadata operation/J and version4 inner definition persists; no separate restore flags or metadata store. |
| Dispose/unregister | Only this adapter's registrations are retired; active scoped reads use the existing host abort/lifetime. No Files write or foreign ownership cleanup is introduced. |

Conformance, invented target IDs, manufactured roughness/position/fit results,
new UI, assembly/printer semantics, old default changes and new Native ABI are
outside this checkpoint. Root must compose backend/metadata/renderer consumers
and complete public acceptance/independent source+archive/math+actual SVG proof.
