# Circuit Lab and Digital Logic document operations

Both windows require `host.documentOperations` from the shared `mountApp` service. Circuit Lab reserves open/import/example replacement and local save before picker/read/write; its path field provides Save As. Digital Logic reserves project open, retry/initial load, example replacement, project Save/Save As via its path field, folder pickers, and truth-table export. Save controls reflect shared per-window and same-file claims. Destination paths use `mirror:` plus normalized mirror paths, and local snapshot revision handling remains responsible for retaining newer edits. No save is queued; background server sync is outside the operation. `readBounded` receives the token signal when present; the compatibility `read` fallback does not support cancellation and is checked for validity before publication. Writes are not claimed to be physically cancellable after dispatch.

`tests/document-operations-circuit-browser.test.mjs` passed in an isolated real Chromium at 1366x900 and 390x844. The actual DigitalJS package rendered a diagram and computed a truth table; the actual Circuit Lab ngspice WASM worker ran the voltage-divider example. Held in-memory storage verified open/save busy buttons, picker cancellation, Circuit Lab Save As and write failure/retry, Digital Logic same-file peer blocking, unrelated-file usability, Save As, CSV export, edit-during-save dirty status, disposal claim release and abort signal delivery to a deliberately non-cooperative bounded-read test double. It did not verify real signed storage, genuine cancellation of an underlying read/write, physical phone interaction, or production asset integration. No production or main site changes were made.
